delivery-eta API

가게에서 배달지까지의 거리와 밀려 있는 주문 수로 배달 예상 시간(분)을 알려 주는 API 입니다.

엔드포인트

GET/이 소개 페이지
GET/health서비스 상태와 현재 예측 구현체 이름
POST/eta배달 예상 시간 계산
GET/docsSwagger UI (대화형 API 문서)

POST /eta

필드타입설명
distance_kmnumber ≥ 0가게에서 배달지까지 거리(km)
pending_ordersinteger ≥ 0지금 밀려 있는 주문 수

음수이거나 숫자가 아닌 값은 422 로 거부합니다.

요청 예시 
curl -X POST /eta \
  -H "Content-Type: application/json" \
  -d '{"distance_km": 2.0, "pending_orders": 3}'

응답 예시

{"minutes": 22.0, "model": "rule"}
